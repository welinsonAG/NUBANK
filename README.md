# 💳 Clone Nubank UI

Projeto front-end desenvolvido com o objetivo de recriar a interface moderna do Nubank, focando em responsividade, boas práticas de código e experiência do usuário.

---
![preview](./img/fundo-nubank.png)

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Flexbox
* Responsividade (Mobile First)

---

## 🎯 Funcionalidades

* Layout moderno inspirado no Nubank
* Design responsivo (desktop e mobile)
* Seções organizadas (hero, produtos, cartões e contato)
* Botões interativos
* Links para redes sociais
* Estrutura limpa e reutilizável

---

## 📱 Responsividade

O projeto foi desenvolvido com foco em adaptação para diferentes tamanhos de tela, garantindo uma boa experiência tanto em dispositivos móveis quanto em desktop.

---

## 💡 Aprendizados

Durante o desenvolvimento, foram trabalhados:

* Estruturação de layout com HTML semântico
* Estilização com CSS moderno
* Uso de Flexbox para organização
* Boas práticas de UI/UX
* Organização de código para escalabilidade
